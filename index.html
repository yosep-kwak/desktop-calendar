바탕화면 캘린더

Windows 바탕화면에 놓아 두는 개인용 달력 위젯입니다. 본인의 구글 캘린더와 구글 할 일(Tasks)을 달력에 보여 주고, 위젯에서 바로 만들고 고칠 수 있습니다.

하는 일

  • 한 달 달력과 일정 목록을 바탕화면에 표시합니다.
  • 구글 캘린더의 일정을 읽고, 새로 만들고, 수정하고, 삭제합니다.
  • 구글 할 일(Tasks)을 읽고, 만들고, 완료 처리하고, 삭제합니다.
  • 일정 알림을 Windows 알림으로 보여 줍니다.

구글 계정 정보를 쓰는 방식

이 프로그램은 사용자의 PC에서만 실행되며, 구글 계정의 데이터는 사용자의 PC와 구글 서버 사이에서만 오갑니다. 만든 사람을 포함해 다른 어디로도 보내지 않습니다. 자세한 내용은 개인정보처리방침에 있습니다.

누가 쓰나요

만든 사람이 직접 쓰려고 만든 개인용 프로그램입니다. 판매하거나 배포하지 않습니다.
