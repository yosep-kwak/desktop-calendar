바탕화면 캘린더

개인정보처리방침

바탕화면 캘린더는 사용자의 PC에서만 실행되는 개인용 프로그램입니다. 서버가 없고, 사용자의 정보를 모으거나 다른 곳으로 보내지 않습니다.

접근하는 구글 계정 정보

사용자가 구글 로그인 화면에서 허용한 범위 안에서만 접근합니다.

  • 캘린더 목록 (읽기): 어떤 캘린더가 있는지, 이름과 색을 표시하기 위해
  • 캘린더 일정 (읽기와 쓰기): 일정을 달력에 보여 주고, 사용자가 위젯에서 만들거나 고치거나 지운 것을 구글 캘린더에 반영하기 위해
  • 할 일(Tasks) (읽기와 쓰기): 할 일을 달력에 보여 주고, 사용자가 만들거나 완료하거나 지운 것을 구글 Tasks에 반영하기 위해

정보가 오가는 곳

위 정보는 사용자의 PC와 구글 서버 사이에서만 직접 오갑니다. 이 프로그램을 만든 사람이나 제3자에게 전송되지 않으며, 광고나 사용 통계 수집에도 쓰이지 않습니다.

PC에 저장되는 것

다음 내용이 사용자의 PC(%APPDATA%\desktop-calendar 폴더)에만 저장됩니다.

  • 구글 로그인 정보(토큰): Windows의 암호화 기능으로 암호화해 저장
  • 프로그램을 켰을 때 바로 보여 주기 위한 최근 일정과 할 일의 사본
  • 설정, 프로젝트 분류, 달력에서 빼서 보관해 둔 일정

공유와 판매

어떤 정보도 다른 사람이나 회사와 공유하거나 판매하지 않습니다.

구글 API 서비스 사용자 데이터 정책

이 프로그램이 구글 API에서 받은 정보를 사용하고 다른 앱으로 넘기는 방식은, 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

접근을 끊고 정보를 지우는 방법

  • 위젯의 설정에서 로그아웃을 누르면 PC에 저장된 로그인 정보가 지워집니다.
  • 구글 계정의 서드 파티 앱 및 서비스 화면에서 이 앱의 접근 권한을 언제든지 삭제할 수 있습니다.
  • %APPDATA%\desktop-calendar 폴더를 지우면 PC에 저장된 내용이 모두 사라집니다.
