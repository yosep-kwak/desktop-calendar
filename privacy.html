바탕화면 캘린더

개인정보처리방침

바탕화면 캘린더는 사용자의 PC에서만 실행되는 개인용 프로그램입니다. 서버가 없고, 사용자의 정보를 모으거나 다른 곳으로 보내지 않습니다.

접근하는 구글 계정 정보

사용자가 구글 로그인 화면에서 허용한 범위 안에서만 접근합니다.

  • 캘린더 목록 (읽기): 어떤 캘린더가 있는지, 이름과 색을 표시하기 위해
  • 캘린더 일정 (읽기와 쓰기): 일정을 달력에 보여 주고, 사용자가 위젯에서 만들거나 고치거나 지운 것을 구글 캘린더에 반영하기 위해
  • 할 일(Tasks) (읽기와 쓰기): 할 일을 달력에 보여 주고, 사용자가 만들거나 완료하거나 지운 것을 구글 Tasks에 반영하기 위해

접근하는 네이버 계정 정보

사용자가 설정에서 네이버 캘린더를 직접 연결한 경우에만 접근합니다. 연결하지 않으면 네이버와는 아무것도 주고받지 않습니다.

  • 네이버 캘린더의 캘린더 목록, 일정, 할 일 (읽기와 쓰기): 달력에 보여 주고, 사용자가 위젯에서 만들거나 고치거나 지운 것을 네이버 캘린더에 반영하기 위해
  • 네이버 아이디와 애플리케이션 비밀번호: 네이버 캘린더가 다른 프로그램에 열어 둔 연결 방식(CalDAV)이 이 둘로 로그인하기 때문에 받습니다. 네이버 계정의 원래 비밀번호는 받지 않습니다. 메일 등 캘린더가 아닌 정보에는 접근하지 않습니다.

접근하는 아이클라우드(애플), 페이슈 계정 정보

사용자가 설정에서 직접 연결한 경우에만 접근합니다. 방식은 네이버와 같습니다.

  • 아이클라우드 캘린더의 캘린더 목록과 일정 (읽기와 쓰기): Apple 계정(이메일)과 앱 암호로 연결합니다. Apple 계정의 원래 비밀번호는 받지 않습니다. 메일, 연락처 등 캘린더가 아닌 정보에는 접근하지 않습니다.
  • 페이슈(飞书) 캘린더의 캘린더 목록과 일정 (읽기와 쓰기): 페이슈가 만들어 주는 CalDAV 사용자 이름과 비밀번호로 연결합니다.

구독 캘린더

사용자가 넣은 주소(.ics)에서 캘린더 파일을 받아 와 읽기 전용으로 보여 줍니다. 그 주소의 서버에는 파일을 달라는 요청만 보내고, 사용자의 정보는 보내지 않습니다.

정보가 오가는 곳

위 정보는 사용자의 PC와 구글 서버, 그리고 사용자가 연결한 서비스(네이버, 애플, 페이슈)의 서버 사이에서만 암호화된 연결로 직접 오갑니다. 이 프로그램을 만든 사람이나 제3자에게 전송되지 않으며, 광고나 사용 통계 수집에도 쓰이지 않습니다. 한 서비스에서 받은 정보를 다른 서비스로 보내는 일은 사용자가 일정을 직접 다른 캘린더로 옮길 때뿐입니다.

PC에 저장되는 것

다음 내용이 사용자의 PC(%APPDATA%\desktop-calendar 폴더)에만 저장됩니다.

  • 구글 로그인 정보(토큰): Windows의 암호화 기능으로 암호화해 저장
  • 네이버 아이디와 애플리케이션 비밀번호(연결한 경우): Windows의 암호화 기능으로 암호화해 저장
  • Apple 계정과 앱 암호, 페이슈 CalDAV 사용자 이름과 비밀번호(연결한 경우): Windows의 암호화 기능으로 암호화해 저장
  • 구독한 캘린더의 주소: Windows의 암호화 기능으로 암호화해 저장
  • 프로그램을 켰을 때 바로 보여 주기 위한 최근 일정과 할 일의 사본
  • '이 컴퓨터' 캘린더에 만든 일정과 할 일: 어느 계정에도 올라가지 않고 이 PC에만 있음
  • 설정, 프로젝트 분류, 달력에서 빼서 보관해 둔 일정

공유와 판매

어떤 정보도 다른 사람이나 회사와 공유하거나 판매하지 않습니다.

구글 API 서비스 사용자 데이터 정책

이 프로그램이 구글 API에서 받은 정보를 사용하고 다른 앱으로 넘기는 방식은, 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

접근을 끊고 정보를 지우는 방법

  • 위젯의 설정에서 로그아웃을 누르면 PC에 저장된 로그인 정보가 지워집니다.
  • 구글 계정의 서드 파티 앱 및 서비스 화면에서 이 앱의 접근 권한을 언제든지 삭제할 수 있습니다.
  • 위젯의 설정에서 네이버 연결 끊기를 누르면 PC에 저장된 네이버 로그인 정보가 지워집니다. 애플리케이션 비밀번호는 네이버 내정보의 보안설정에서 삭제할 수 있습니다.
  • 아이클라우드와 페이슈도 설정에서 연결 끊기를 누르면 PC에 저장된 로그인 정보가 지워집니다. 앱 암호는 Apple 계정 화면에서, 페이슈의 CalDAV 비밀번호는 페이슈 설정에서 삭제할 수 있습니다.
  • 구독 캘린더는 설정에서 구독 끊기를 누르면 저장된 주소가 지워집니다.
  • %APPDATA%\desktop-calendar 폴더를 지우면 PC에 저장된 내용이 모두 사라집니다.
